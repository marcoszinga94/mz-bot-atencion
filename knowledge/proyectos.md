# Proyectos y experiencia

## Tipos de soluciones desarrolladas

Como desarrollador web full-stack, Marcos trabaja en una amplia variedad de proyectos, entre ellos:

- Sistemas de gestión de historias clínicas para consultorios y centros de salud, con recetas digitales, órdenes de estudios, derivaciones y módulo de turnos con recordatorios.
- Visualizadores de datos económicos con gráficos interactivos y alertas personalizadas.
- Sistemas de gestión para gimnasios: registro de socios, planes de entrenamiento, control de asistencias, pagos y reporting.
- Plataformas de reservas online para profesionales, con recordatorios automáticos y sincronización con calendarios.
- Sitios web institucionales para empresas, con catálogos, galerías, blog y formularios de contacto inteligentes.
- Aplicaciones web de apoyo a la salud y el bienestar, con herramientas de seguimiento y recursos.

## Stack

React, TypeScript, Astro, TailwindCSS, Supabase, Node.js, entre otras tecnologías modernas.
